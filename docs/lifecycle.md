# 事件与组件生命周期（A11）

主窗口原先在 await 之后调用 onUnmounted，无法可靠归属当前组件；事件取消函数及异步创建的 watcher 也未保存。头像、磁贴样式和分组样式窗口有类似事件回收遗漏，主题监听直接调用 listen 且未处理取消与失败。

现在 useDisposalScope 在 setup 同步注册卸载钩子，管理事件取消、watcher 和延迟任务。异步流程在组件卸载后才交回的资源会立即释放；释放操作可重复调用，单个清理失败不阻断其他清理。Tauri 原生监听注册仍由桥接层处理晚到的 unlisten，确保两层异步过程都可回收。

具体变更：

- 主窗口保存所有桌面事件及异步 watcher 的取消函数，移除 await 后注册的卸载钩子；退出初始化时检查组件是否已卸载。
- 主题事件统一经过桥接，随根组件卸载，并复用桥接错误提示。
- 头像、磁贴样式、分组样式窗口回收订阅；关闭后的初始化不继续注册事件。
- 回收主窗口鼠标和滚动监听、模糊层延迟任务与刷新计时器；设置和快捷键窗口的提示定时器也随组件释放。
- 网格添加分组使用具名回调；列表拖动、磁贴拖动、裁剪拖动在卸载时移除全局鼠标监听。裁剪弹层隐藏时停止拖动，关闭后的图片回调不再提交结果。
- 主窗口释放自己注册的全局界面回调，避免持有已卸载实例；已有新实例接管时不删除新回调。

## 验证

`npm run test:lifecycle` 的 5 项测试覆盖幂等回收、异常清理隔离、延迟任务取消，以及使用 Vue 实际生命周期反复挂载和关闭期间异步注册晚到。14 项数据保护测试、10 项桥接测试、TypeScript 检查与前端生产构建通过。构建仍提示既有的大 bundle 问题。

测试使用 Vue 自定义 renderer，没有启动真实 WebView。桌面验收仍需反复打开/关闭头像及样式窗口，确认事件每次只响应一次；在加载中关闭窗口、拖动中关闭菜单，确认没有残留回调、拖动状态或 Vue 生命周期警告。已经发出的原生操作不会因组件卸载而自动撤销。
