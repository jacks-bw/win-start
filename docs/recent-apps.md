# 最近添加（A4）

“最近添加”采用本程序的首次发现时间，不代表 Windows 安装时间。首次完整扫描建立基线，已有程序不显示为新增；之后新发现的入口显示 7 天，按时间倒序最多显示 5 个，已放进文件夹的应用继续从此区域排除。界面标题提示具体口径。

Rust 在 `%APPDATA%\win-start\app-discovery.json` 保存应用 ID 与首次发现时间（Unix 毫秒）。基线条目的时间为空；历史 ID 不因应用暂时消失而删除，因此同一 ID 再出现不会重置时间。不同路径或不同 AUMID 形成不同 ID，会作为新入口处理。

首次扫描不完整时只记录已观察到的基线入口，不宣告基线完成；首次完整扫描补齐其余基线。完成基线后，部分扫描也可记录明确发现的新入口，但不会删除缺失记录。

读写由后端互斥锁串行保护，沿用原子保存。损坏或不可读的文件不会被当作空记录覆盖；写入失败不发布尚未保存的新时间。历史记录失败只增加可见提示，不阻止应用列表扫描和启动。首次发现不追溯升级前的历史，删除记录文件后下次完整扫描会重新建立基线。

前端按时间筛选和排序；重扫及菜单再次打开后的刷新检查会更新过期结果，即使该次因 60 秒节流而不执行原生扫描。系统时间回拨导致时间处于未来时，暂不显示该条目，避免错误标记。菜单持续打开时不会额外启动周期计时器。

验证包括 3 项 Rust 测试（基线/部分扫描、重扫及重启、坏文件和失败保存），4 项前端回归测试（边界、排序及上限、节流后的过期、可见错误提示），以及现有桥接字段映射测试。完整测试现为 40 项 Rust、18 项数据保护、10 项桥接、5 项生命周期测试。真实桌面仍需验证：首次建立基线后添加快捷方式，重扫出现；重启仍保持；暂时移走再恢复同一入口不变成最新条目。
